Banque Misr App 🇪🇬
A simple banking app UI built with Kotlin and Jetpack Compose, inspired by Banque Misr.
✨ Features
- 🔐 Login: Username and password input fields.
- 👁️ Password Visibility: Show or hide the password.
🌐 Responsive Language Switching: Switch between Arabic and English with a responsive UI that adapts to the selected language.
- 🔑 Forgot Password: Forgot username or password option.
- 📞 Contact Us: Help and customer support section.
- 💰 Banking Services: Quick access to:
  - Our Products
  - Exchange Rates
  - Security Tips
  - Nearest Branch or ATM
🛠️ Technologies
- Kotlin
- Jetpack Compose
- Material 3
- AppCompat
- Android Studio
Note: This project focuses on the user interface. Login functionality and service actions have not been implemented yet.
